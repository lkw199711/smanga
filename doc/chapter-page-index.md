# 章节页索引

首版为本地散图目录章节保存页图列表。Smanga 现在每次打开散图章节都会递归枚举，对各条目查询文件状态，再过滤和排序。读索引可以省掉重复的文件系统访问，对页数多、含子目录或经常回看的章节更有价值。单层小目录的热缓存枚举也可能很快，收益以实测为准。[当前阅读逻辑](../smanga-adonis/app/controllers/chapters_controller.ts)

压缩包章节首版继续复用已有解压缓存。网盘暂缓支持散图章节，网盘压缩包的读取策略见[网盘支持优化](cloud-storage-optimization.md)。

## 存储模型

新增独立表 `chapterPageIndex`，每个章节保存一条记录。调用方通常一次取整章页表，使用 JSON 数组即可。SQLite、MySQL 和 PostgreSQL 使用一致的数据结构，文本列需容纳大章节的列表。

| 字段 | 用途 |
| --- | --- |
| `chapterId` | 主键，关联 `chapter`，章节记录删除时清理索引 |
| `sourceKey` | 由 `pathId` 和当前存储的 `chapterPath` 生成的源标识，用来识别重新绑定或章节路径变化 |
| `indexedAt` | 最近一次完整枚举并发布索引的时间 |
| `pagesJson` | 候选图片路径数组，例如 `["001.jpg", "002.jpg", "附录/001.webp"]` |

图片路径相对于章节目录，统一用 `/` 分隔。服务端先解析当前章节目录，再拼接页路径并校验仍在允许的目录范围内。绑定存储根的章节在同一份内容迁移挂载点后可以继续复用索引。存储根指向另一份内容时，清除该根下的旧索引，即便相对路径相同。首版只保存候选路径，避免为了索引逐页采集文件大小和修改时间。索引是可重建的派生数据，阅读进度和书签继续由原有记录管理。[章节数据模型](../smanga-adonis/prisma/sqlite/schema.prisma) · [路径解析](../smanga-adonis/app/services/library_path_service.ts)

## 建立与更新

| 触发场景 | 处理方式 |
| --- | --- |
| 新增本地散图章节 | 扫描时生成。扫描已经取得完整页图列表时直接复用 |
| 升级后的旧章节首次打开 | 索引缺失时按需枚举和写入。同一章节的并发首读合并处理，避免升级后集中遍历全库 |
| 已有章节补页、删页或改名 | 扫描发现章内变化后排入重建。对有子目录或近期阅读的章节低频复查，补足仅看父目录修改时间容易遗漏的变化 |
| 手动修复或在应用外编辑本地文件 | 提供「刷新本章页索引」，跳过修改时间判断，只枚举这一章。应用内修改页文件的操作在完成后走同一刷新入口 |
| 替换同名图片 | 页路径未变，列表可继续使用。如有该页的图片内容缓存，刷新时清理对应缓存 |
| 章节删除、换源或类型变化 | 删除或失效旧索引。新源符合本地散图条件时，按新源重新生成 |

现有增量扫描会比较漫画目录修改时间和最新章节记录的更新时间，可能跳过内部子目录已经变化的章节。索引刷新要有独立的章级触发条件，手动修复也无需调用现有完整重扫。[现有扫描判断](../smanga-adonis/app/services/scan_manga_job.ts)

同一轮完整读取成功后一次性替换整条索引。发布前复核 `sourceKey` 和当前重建任务的顺序，防止换源前的任务或较旧结果覆盖新索引。读取失败或结果明显异常缩水时保留旧索引并记录原因，复查确认后才发布缩水后的结果。旧索引只在源标识仍一致时使用。

## 阅读与兼容

Web 阅读器先按 `chapterId` 查索引，命中后沿用现有排除规则和排序规则，在内存里组装页表。索引保存候选文件列表，排序或排除配置更新后，下次取页表即可生效。OPDS 接入同一份候选列表时，继续使用自己的字符串排序和页码规则。每张图片仍通过原有读取入口读取，权限检查和图片内容缓存独立生效。[Web 阅读入口](../smanga-adonis/app/controllers/chapters_controller.ts) · [OPDS 阅读入口](../smanga-adonis/app/controllers/opds_controller.ts)

后续如需为压缩包建索引，应在本地解压成功后生成，路径相对于本次解压目录。索引与该次解压产物绑定，清理解压缓存、替换压缩包或强制重解压时随之失效。普通库扫描无需提前解压整库。

## 验收

- 用含中文文件名、多层目录、页码 `2` 和 `10` 的章节，对比接入前后的 Web 和 OPDS 页表、排序及排除结果。
- 验证旧章节首次打开能补建，后续打开在索引命中时不再递归枚举。分别记录小目录、多页目录及冷启动场景的耗时和文件系统调用次数。
- 验证补页、删页、改名和同名覆盖后的行为。手动刷新能覆盖父目录修改时间不变的场景，扫描失败不会发布半份页表。
- 验证并发刷新、章节换源及删除。旧任务不能覆盖新页表，过时索引不能用于新源，已有阅读进度保持关联。
